# WebMCP-Challenge

A modern web application built to explore the agent-native web. This project implements the WebMCP standard to expose structured tools directly to AI agents, eliminating the need for UI scraping. 

## Features
* **Human-Agent Collaboration:** Users interact with a clean React interface while agents access the same data catalog via WebMCP.
* **Registered Tools:** Includes `document.modelContext.registerTool()` implementations for automated search and data retrieval.
* **Tech Stack:** Next.js, TypeScript, Node.js, and PostgreSQL/SQLite.

## How to Test
Open the live URL in the ChatGPT in-app browser or Google Chrome with the `chrome://flags/#enable-webmcp-testing` flag enabled.
